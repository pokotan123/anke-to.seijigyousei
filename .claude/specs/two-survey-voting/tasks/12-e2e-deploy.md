# Task 12: E2Eテスト・デプロイ

## Status: pending

## PRD Reference: Section 8 (Success Criteria)

## Dependencies: Task 01-11

## Description
登録→メール送信→投票の一連フローをE2Eテスト。全成功基準を検証し、本番デプロイ。

## Implementation Steps

1. ローカルでの統合テスト
   - 管理者: 投票用アンケート作成・公開
   - 管理者: 登録用アンケート作成（email質問含む）、投票surveyにリンク、公開
   - 投票者: 登録用アンケートに回答（メールアドレス入力）
   - 管理者: 投票者一覧で登録確認
   - 管理者: 投票リンク一括送信
   - 投票者: メールのリンクから投票ページアクセス
   - 投票者: 全問投票、完了確認
   - 投票者: 同一リンクで再投票→エラー確認
2. セキュリティテスト
   - 不正voter_tokenでのアクセス→404
   - 匿名でrequire_registration=trueのsurveyに投票→403
   - 同一メールで2回登録→409
   - レースコンディション: 同時2リクエスト→1つだけ成功
3. Railwayデプロイ
   - DBマイグレーション実行（本番）
   - ビルド・デプロイ
4. Vercelデプロイ
   - フロントエンドビルド・デプロイ
5. 本番での動作確認

## Acceptance Criteria
- [ ] 登録→投票の一連フローが正常に動作

- [ ] 二重投票が防止される
- [ ] 匿名投票ガードが動作
- [ ] レースコンディションが発生しない
- [ ] 既存の匿名投票フローが壊れていない
- [ ] 本番環境で正常稼働
